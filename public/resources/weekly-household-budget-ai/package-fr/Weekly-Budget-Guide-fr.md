# Budget familial hebdomadaire avec l’IA

Un guide pratique pour organiser un montant hebdomadaire limité sans laisser l’IA prendre les décisions financières.

## Exemple réel : 300 TND pour une semaine

Une famille de deux adultes et un enfant dispose de 300 TND pour l’alimentation, l’entretien, le transport et les urgences. Le workflow aide à poser les bonnes questions, répartir le montant, créer une liste priorisée, suivre les dépenses réelles et ajuster le plan.

## Étapes

1. Saisir le montant, la famille, les jours, les stocks et les coûts fixes.
2. Poser les questions manquantes au lieu d’inventer.
3. Répartir entre essentiels, frais, protéines, entretien, transport et réserve.
4. Classer les achats : indispensable, utile, reportable.
5. Enregistrer les prix réels et calculer le solde.
6. Revoir le plan si le montant ou les prix changent.

## Où utiliser ce workflow

- Manuel avec ChatGPT, Claude ou Gemini.
- Semi-automatique avec Google Sheets.
- Automatisé avec Make ou n8n vers Notion, Sheets ou un brouillon de rappel.

L’IA organise et calcule. Une personne confirme les prix, les priorités et toute action liée à l’argent.

## Sécurité

Ce kit organise un budget, il ne constitue pas un conseil financier. Ne partagez jamais vos cartes, identifiants bancaires ou données sensibles. Vérifiez les prix localement.
