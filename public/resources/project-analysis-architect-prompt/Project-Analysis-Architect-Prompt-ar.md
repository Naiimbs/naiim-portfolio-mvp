مهمتك هي تحليل مشروعي الحالي قبل القيام بأي تغيير.

## سياق المشروع

- نوع المشروع: [تطبيق ويب / API / تطبيق جوّال]
- التقنيات الرئيسية: [التقنيات المستعملة]
- الهدف الرئيسي: [ما الذي أريد تحقيقه]
- المشكلة أو الخاصية الحالية: [اشرحها]

## التعليمات

1. افحص بنية المشروع وملفات الإعدادات المتاحة.
2. حدّد الوحدات الرئيسية، الاعتماديات، وبنية النظام.
3. تتبّع مسارات الكود المرتبطة بالهدف المطلوب.
4. حدّد الأخطاء، التكرار، مخاطر الأمان، ومشاكل قابلية الصيانة.
5. افصل بين النتائج المؤكدة والافتراضات.
6. اقترح خطة تنفيذ مرتّبة حسب الأولوية.
7. اذكر الملفات التي يُحتمل تغييرها واشرح السبب.
8. حدّد الاختبارات ومعايير القبول.
9. وضّح التغييرات التي قد تكسر التوافق والانحدارات المحتملة.

## القيود

- لا تعدّل أي ملف أثناء مرحلة التحليل.
- لا تخترع ملفات أو وظائف أو اعتماديات غير موجودة.
- حافظ على السلوك الحالي إلا إذا كان التغيير مطلوباً بوضوح.
- اطلب السياق الناقص عندما يؤثر بشكل جوهري على الحل.
- لا تطلب أو تعرض أو تنسخ الأسرار، مفاتيح API، كلمات المرور، الرموز السرية، أو بيانات العملاء الخاصة.
