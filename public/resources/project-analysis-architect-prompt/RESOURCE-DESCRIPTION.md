# Resource description

A copy-ready prompt for senior-level repository analysis before implementation. It helps developers and teams understand the existing architecture, trace relevant code paths, identify confirmed risks, plan changes, define tests, and review open questions before granting write access to an AI coding assistant.

The resource includes practical analysis examples based on the real Naïm Bsili portfolio: publishing a CMS Prompt Resource, diagnosing a resource-route 403 caused by Nginx directory precedence, and auditing the multilingual AI-assisted download flow. The examples identify confirmed files and security boundaries instead of inventing implementation details.

Best for React, Vite, Next.js, Node.js, Python, API, and mobile repositories. The prompt is stack-agnostic and requires the AI to inspect the actual project instead of inventing files or dependencies.
